# Multi-Core Load Balancing Scheduler

A Python project for simulating how work can be distributed across multiple CPU cores, with supporting analysis and visualizations.

## Project files

- `scheduler.py` contains scheduling logic.
- `app.py` provides the application entry point.
- `visualizations.py` and `export.py` support result presentation and export.

Review the included requirements and project notes for environment-specific setup instructions before running the application.
